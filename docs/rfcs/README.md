# RFCs — Athena Request For Comments

An RFC records a proposal for the Athena platform: the problem, objectives, the
decision (when accepted), and the consequences. RFCs complement ADR by
capturing proposals and their status through to acceptance.

## Status conventions

- **Draft** — proposed; design in progress.
- **Accepted** — the decision stands; implementation exists or is committed.
- **Superseded by RFC NNNN** — replaced.
